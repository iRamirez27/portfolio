2D Animation - Autodesk Maya
----------------------------
 This project was a 2D animation for my general Animation 1 class in early 2023. I used mutliple different flat planes and a static camera angle in Maya to create the 2D effect. The frames were compiled and music was added afterwards in Avid Media Composer.
3D Animation - Autodesk Maya
----------------------------
 This project was also created for the final project of my general Animation 1 class. While not fully 3D animated, it does mostly consist of 3D objects. I wanted to make this project more in time with the music, which ended up requiring much more precision in editing the frames. The intent was to emulate movement with the use of both the camera's movement and the eventual movement of the objects surrounding the environment. This editing was also done using Avid Media Composer.
Game and Level Design - Unreal
----------------------------
 This was my final project for my Game Design in Unreal class in fall 2024. We had working throughout the whole semester on different aspects of the design and development process, including the brainstorming and making a concept board. We also broke down the different components of the game itself, like the health bar, the enemy movements, and any other object movement.
